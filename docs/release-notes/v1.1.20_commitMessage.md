feat(powerApps): v1.1.20 — resilient Confirm booking-commit, rebuilt Help screen, smarter class picker

## Context

This commit delivers the **578-EHRM-TrainingSchedulerApp** repo v1.1.20 release — a significant Canvas-app reliability & usability update (a `1.0 → 1.1` minor jump bundling a large body of hands-on editor work) that makes the booking transaction verifiable end-to-end and replaces the stale in-app Help content with a real user guide. The changes were developed hands-on in the Power Apps web editor, exported, and unpacked via `pac canvas unpack`; the resulting source under `./src/powerApps/.unpacked/` (newer dual `layoutDefault/` + `layoutSourceCode/` layout) now reflects the v1.1.20 state.

The Canvas app component version advances from v1.0.12 → v1.1.20, now aligned with the project-wide SemVer release version (`varRepoVersion`, `CanvasManifest.AppDescription`, and the `.zip` bundle all read `1.1.20`).

> ℹ️ **Packaging:** the tracked `.msapp` package was renamed to `v1.1.20_578EHRMTrainingApp.msapp` to match the release (the `.msapp` binary content was not modified — only the filename prefix; KI-01 resolved).

## What changed — Canvas app (src/powerApps/)

### Confirm.fx.yaml — booking-commit refactor
- `btnSubmit` converted from a monolithic inline submit into a **thin orchestrator** that `Select()`-chains dedicated child buttons and defers navigation to a new timer.
- Added `timer_selectBtnsThenNavigate` (timer): `OnTimerEnd` computes `varAllOK` from `varCalendarOK`/`varEmailOK`/`varPatchSuperUsersOK`/`varAnyListPatchOK`, then `Navigate(Success)` (grace delay 2s success / 8s failure / 12s debug).
- Reservation write reorganized into a **tiered fallback cascade** — `btnPatch_detailedPrimary` → `btnPatch_detailedSecondary` → `btnPatch_simplePrimary` → `btnPatch_debugSimplified` — each tier writing to **both** `'Desk Reservations'` and `backupList_DeskReservations`; success via `CountRows(col) > 0 And CountIf(col, Not(ok)) = 0`; new `varSubmissionID = Text(GUID())`.
- Control renames: `btnPostCalendarItem` → `btnOutlook_PostCalendarItem`; `btnSendAsEmail` → `btnOutlook_SendAsEmail`; `btnPatchDetailedMainList` → `btnPatch_detailedPrimary`; `btnPatchDetailedBackupList` → `btnPatch_detailedSecondary`; `btnPatchSimpleMainList` → `btnPatch_simplePrimary`; `btnPatchSuperUserList` → `btnPatch_superUserList`. Legacy `btnOldSubmit` retained but fully commented out.
- Email fix: confirmation-email `Cc` typo `varAttendees` → `var_Attendees` (CC recipients now resolve); `Cc` now also includes submitter + optional attendees. (The three PM/admin addresses in the `Cc`/gates are intentionally hard-coded for resilience — by design.)

### ReleaseNotes.fx.yaml — Help screen rebuilt
- `HtmlText1` → `htmlText_userGuide`: stale static content replaced with a 10-step end-user Quick-Start guide.
- Added `htmlText_releaseNotes`: full project-changelog HTML render for admins.
- Visibility gating: `htmlText_userGuide.Visible = If(user_isAdmin, false, true)`; the two viewers are mutually exclusive.

### POCSUPERVISOR.fx.yaml — class/scenario picker
- `dropdown_RolePicker`/`ScenarioPicker`/`DateTimePicker` re-pointed from live `MasterScheduleList`/`'Learning Lab Sessions'` to Hines-scoped collections `col_nationalEHRMLearningLabSessions`/`col_MasterSchedule`.
- `dropdown_DateTimePicker.Items` adds active-session filter `(IsBlank(sessionActive_text) || sessionActive_text <> "false")`.
- Added cascade `Reset()` on `RolePicker.OnChange`/`ScenarioPicker.OnChange`; `HtmlText8_2.Height` grows for longer descriptions. (Edit-form data-card churn is reordering only — no field/column change.)

### Screen1.fx.yaml — experimental data-explorer (not wired to menu)
- Power BI embed set `Visible: =false`; added `Gallery7` (Learning Lab Sessions) + `Gallery8` (MasterScheduleList) browse galleries with Role/Scenario dropdown filters and count labels; placeholder `Button1`.

### App / Dashboard / DebuggingScreen / chkWeekDays
- `App.fx.yaml`: `varRepoVersion` "1.0.12" → "1.1.20"; `Facility.Value = Text("Hines")` → `= "Hines"`.
- `Dashboard.fx.yaml`: `Timer3` → `timer_loadGlobalVariables`; `OnVisible` reformat.
- `DebuggingScreen.fx.yaml`: dev-only cleanup lines commented out.
- `chkWeekDays.fx.yaml`: added `Set(var_timerPopUP_SubmitScreen, Blank());` to disarm the new Confirm timer.

### CanvasManifest.json / Connections / DataSources
- `CanvasManifest.json`: `AppDescription` v1.0.12 → v1.1.20; `BindingErrorCount` 0 → 24 (known regression on the `Success` screen — see KI-02; fix planned as a follow-up patch).
- `Connections.json`: a **Microsoft Teams** connection was added as an intentional placeholder (not yet wired to any formula; may be removed later — KI-03). *(Not advertised in `src/solution.xml`.)*
- `DataSources/MasterScheduleList.json` + `pkgs/TableDefinitions/MasterScheduleList.json`: added `sessionActive_text` (SharePoint list schema extraction deferred to a future patch — KI-04).
