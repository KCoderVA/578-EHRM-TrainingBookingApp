# EHRM Training & Booking App — Release Notes (v0.2.0)

- **Release date**: 2026-07-07
- **Release type**: Maintenance (Repository hygiene, developer tooling, gitignore correctness)
- **Previous release**: v0.1.1 (2026-05-28)

## Executive summary

v0.2.0 is a repository hygiene and developer-tooling release that corrects several `.gitignore` issues that had silently affected the public repository since initial setup.

The primary fix addresses an overly broad `*_temp*` glob pattern that was case-insensitively matching `_TEMPLATE` on Windows, which caused the GitHub PR template and release notes template to be excluded from version control. Additionally, 9 Visual Studio IDE cache files and 8 temporary scratch files that were inadvertently committed are now removed from tracking, and the VS Code workspace configuration has been enriched with editor settings, recommended extensions, and embedded task definitions.

No functional changes are intended to the Power Apps Canvas app or Power Automate flow logic in this release.

## Root cause: `*_temp*` pattern

The original `.gitignore` line `*_temp*` was intended to catch temporary files. On Windows, where git uses case-insensitive pattern matching by default, this glob also matched `_TEMP` at the start of `_TEMPLATE`:

```
PULL_REQUEST_TEMPLATE.md
                ^^^^
           *_temp* matches here (case-insensitive)
```

The fix replaces these broad globs with targeted directory and extension rules (`/tmp/`, `*.tmp`) that achieve the original intent without false positives on legitimate `TEMPLATE` files.
