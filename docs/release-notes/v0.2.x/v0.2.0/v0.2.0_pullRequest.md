## Summary

This PR prepares the **EHRM Training & Booking App** repo for the **v0.2.0** release by:

- Rewriting `.gitignore` to fix an overly broad `*_temp*` pattern that was silently hiding `*_TEMPLATE*` files from the public repository
- Removing 9 Visual Studio IDE cache files (`.vs/`) and 8 temporary scratch files (`tmp/`) from git tracking
- Restoring `.github/PULL_REQUEST_TEMPLATE.md` and `docs/release-notes/RELEASE_TEMPLATE.md` to version control
- Enriching the VS Code workspace configuration with editor settings, recommended extensions, and embedded task definitions
- Updating Copilot agent instructions with terminal workaround documentation and re-enabled release guidance

No changes are intended to the underlying Canvas app or Power Automate flow logic in this PR; this is a repository hygiene and developer-tooling release.

## Root cause analysis: `*_temp*` pattern bug

The original `.gitignore` contained the glob `*_temp*` intended to catch temporary files. On Windows (where git pattern matching is case-insensitive by default), this pattern also matches `_TEMP` inside `_TEMPLATE`:

- `PULL_REQUEST_TEMPLATE.md` → contains `_TEMP` at the start of `_TEMPLATE` → **matched**
- `RELEASE_TEMPLATE.md` → same issue → **matched**

The fix replaces these broad globs with targeted rules (`/tmp/`, `*.tmp`) that achieve the original intent without false positives.
