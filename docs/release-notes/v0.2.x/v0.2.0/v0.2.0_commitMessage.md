chore(release): v0.2.0 repository hygiene — .gitignore rewrite, untrack IDE/temp files, restore templates

## Context

This change set prepares the **EHRM Training & Booking App** repository for the **v0.2.0** release.

The repository's `.gitignore` contained several issues that had accumulated since initial setup: overly broad glob patterns were silently hiding legitimate files (PR template, release template), while machine-specific IDE cache files (`.vs/`) and temporary scratch files (`tmp/`) had been committed to the public repo. This release corrects all of those issues and enriches the developer workspace configuration.

## What changed

### `.gitignore` rewrite

- Removed overly broad `*_temp*` and `*temp_*` patterns that were incorrectly matching `*_TEMPLATE*` files (case-insensitive on Windows), which caused `.github/PULL_REQUEST_TEMPLATE.md` and `docs/release-notes/RELEASE_TEMPLATE.md` to be excluded from the repository.
- Removed `.gitattributes` and `.editorconfig` from the ignore list — these are team-shared configuration files that belong in version control.
- Consolidated redundant rules (`/archive/` + `/archive/**` → `/archive/`; `**/*.bak` + `*.bak` → `**/*.bak`).
- Added missing common ignore patterns: `~$*` (Office temp-lock files), `**/*.log`, `*.swp`, `*.swo`, `*.tmp`.
- Reorganized into clearly labeled sections with comments.

### Files removed from tracking (kept locally)

- **`.vs/` folder** (9 files) — Visual Studio IDE cache, file content indexes (`.vsidx`), workspace user options (`.wsuo`), Copilot indices (`.db`), project settings, and SQLite databases. These are machine-specific and should never be published.
- **`tmp/` folder** (8 files) — temporary probe files, scan results, and scratch text files. These are developer-only local artifacts.

### Files added to tracking (previously hidden)

- **`.github/PULL_REQUEST_TEMPLATE.md`** — standard GitHub PR template, was blocked by `*_temp*` pattern matching `_TEMPLATE`.
- **`docs/release-notes/RELEASE_TEMPLATE.md`** — release notes template, same root cause.

### `.github/copilot-instructions.md` updates

- Added explicit PowerShell terminal `^U` workaround documentation with examples for new-terminal initialization.
- Re-enabled the "Releases, Tags, and Release Notes" guidance section (was previously wrapped in a `<!-- DISABLED -->` HTML comment).
- Updated folder structure references to include `archive/` and `tmp/` conventions.

### `.vscode/578-EHRM-TrainingSchedulerApp.code-workspace` enrichment

- Added workspace folder display name (`578-EHRM-TrainingSchedulerApp`).
- Added editor settings: `trimTrailingWhitespace`, `insertFinalNewline`, `formatOnSave`.
- Added `files.exclude` visibility rules for `.cache` and `dist`.
- Added GitHub/git authentication settings.
- Added recommended extensions list (Copilot, Copilot Chat, GitHub PR, PowerShell, Power Platform, Chat Customizations Evaluations, vscode-icons).
- Embedded PAC CLI task definitions (Canvas unpack/pack, Solution export/unpack) directly in the workspace file.

### Release documentation

- Added v0.2.0 release artifacts under `docs/release-notes/v0.2.x/v0.2.0/`:
  - `v0.2.0_commitMessage.md`
  - `v0.2.0_pullRequest.md`
  - `v0.2.0_releaseNotes.md`
- Updated `CHANGELOG.md` with the v0.2.0 entry.
- Updated `README.md` version badge and current version reference from v0.1.1 to v0.2.0.

## Why

- **Security/hygiene**: `.vs/` files can contain environment-specific data, binary indices, and SQLite databases that have no place in a public repository.
- **Correctness**: `tmp/` files are explicitly designated as local-only per the project's folder conventions but were committed due to being added before the gitignore rule took effect.
- **Completeness**: The PR template and release template are essential GitHub community/governance files that were silently excluded by a pattern bug.
- **Developer experience**: The enriched workspace config provides a consistent baseline for editor behavior, recommended extensions, and task access.
