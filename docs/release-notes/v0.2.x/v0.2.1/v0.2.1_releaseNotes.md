# EHRM Training & Booking App — Release Notes (v0.2.1)

- **Release date**: 2026-07-07
- **Release type**: Patch (documentation update)
- **Previous release**: v0.2.0 (2026-07-07)

## Executive summary

v0.2.1 is a documentation-only patch release that updates `docs/PROJECT_STATUS.md` to accurately reflect the project's current state after the v0.2.0 repository hygiene release. The previous PROJECT_STATUS.md still described the v0.1.1 release and was missing details about repository contents, release history, connectors, and the lessons learned from the `.gitignore` fix.

No functional changes are intended to the Power Apps Canvas app or Power Automate flow logic in this release.

## Highlights

- Comprehensive rewrite of `docs/PROJECT_STATUS.md` to reflect the current v0.2.x project state
- Added release history table covering all five releases (v0.0.1 through v0.2.0)
- Expanded repository contents documentation with links to key architecture and runbook files
- Added `.gitignore` verification step to the release readiness checklist
