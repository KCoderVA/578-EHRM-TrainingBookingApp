feat(canvas-app): v0.3.4 — role-based access control, smart scheduling, calendar modernization, UX improvements

## Context

This commit prepares the **EHRM Training & Booking App** repository for the **v0.3.4** feature release — the first major functional update to the Canvas app since v0.0.2 (January 2026). All changes in this commit originate from hands-on development performed directly in the Power Apps canvas editor. The updated `.msapp` package (`v0.3.4_578EHRMTrainingApp.msapp`) was unpacked via `pac canvas unpack` and the resulting source files under `src/powerApps/.unpacked/` now reflect the v0.3.4 state.

The Canvas app component version advances from v0.0.2 → v0.3.4, now aligned with the project-wide SemVer release version.
