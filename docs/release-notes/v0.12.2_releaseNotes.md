# 578-EHRM-TrainingSchedulerApp - Release Notes (v0.12.2)

- **Release date**: 2026-08-12
- **Release type**: Feature - Go-live readiness release for the Canvas app and aligned repo release artifacts
- **Previous release**: v0.9.27
- **Canvas app component**: v0.9.26 -> **v0.12.2**
- **Power Automate**: `AppUserList` (unchanged in this release)

---

## Executive Summary

This release is a major forward step focused on go-live readiness for the EHRM training scheduling workflow. The Canvas app received meaningful functional and structural updates, including new administrative and meeting workflows, expanded data-source bindings, and stronger reservation persistence pathways. In parallel, project-level version and release artifacts were synchronized so documentation, manifest metadata, and solution versioning are consistent at `0.12.2`.

4 distinct improvement areas were implemented and are documented below:

1. **Screen topology modernization** - Added `ManageUsers` and `CreateMeeting`; removed legacy/obsolete screens.
2. **Data-source and connector expansion** - Broadened SharePoint and M365 connector action usage.
3. **Reservation pipeline resilience** - Reinforced main/fallback/backup booking persistence behavior.
4. **Version and release alignment** - Unified app/package/manifest/project release identity at `0.12.2`.

---

## Changes

### Canvas app - Screen topology modernization

The prior screen set included legacy utility/alternate paths that were no longer aligned with the current operational model. This release modernizes navigation and capability by adding focused screens and removing outdated surfaces.

**What changed:**

- Added screens:
  - `ManageUsers`
  - `CreateMeeting`
- Removed screens:
  - `alt_ManageDesks`
  - `Screen1`
  - `Screen2`
- Net current inventory: 21 screens.

---

### Canvas app - Data-source and connector expansion

Previous app bindings were centered on core reservation and role lists. This release broadens integration coverage for improved scheduling support, admin workflows, and telemetry/audit paths.

**Data sources expanded to include:**

- `MasterScheduleList`
- `SuperUserList`
- `backupList_DeskReservations`
- `Learning Lab Sessions`

**Connection actions now include additional operations such as:**

- `SendEmailV2`
- `SearchUserV2`
- `UserPhotoV2`

---

### Canvas app - Reservation pipeline resilience

Reservation writes in `Confirm` were enhanced with explicit multi-path persistence handling to reduce user-impacting failures.

**Behavior updates:**

- Main patch path retained and strengthened.
- Fallback patch path retained for error scenarios.
- Backup persistence path expanded (`backupList_DeskReservations`).
- Super-user event logging path expanded (`SuperUserList`).

**Deferred fields (unchanged in this release):**

| Field | Current behavior |
|---|---|
| `OutlookEventID` | Deferred (`Blank()`) pending companion automation |
| `OutlookSeriesID` | Deferred (`Blank()`) pending companion automation |
| `ParentReservationID` | Deferred (`Blank()`) pending companion automation |
