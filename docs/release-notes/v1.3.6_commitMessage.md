docs(pages): v1.3.6 — GitHub Pages project overview (docs/index.html) for leadership and implementing developers, .nojekyll, version/doc alignment

## Context

This commit releases the **578 EHRM Training App** repo as **v1.3.6**, a documentation-only patch that adds a graphical GitHub Pages landing page so other VA facilities can evaluate and copy the solution. It has two audiences: executives (summary, KPIs, charts) and the developers who would do the import (architecture, data model, step-by-step import guide). The page was modeled on the Telehealth Schedule & Booking project's overview page. Every metric on it was taken from the repository (release history, `CanvasManifest.json`, Git history). No Power Platform source changed.

No component versions advance: Canvas app stays v1.3.5, the four flows and SharePoint are unchanged, and `src/solution.xml` stays v1.3.5.

---

## What changed — GitHub Pages overview (docs/)

### New `docs/index.html`
- Self-contained HTML/CSS/JS page with no external libraries or CDNs, Apache 2.0 header, VA navy/gold palette.
- Three collapsible chapters with an auto-generated side navigation, active-section highlighting, Collapse/Expand All, a high-contrast toggle, a mobile drawer, and Print / Save PDF.
- **Executive Overview:** at-a-glance summary and 8 KPI tiles (v1.3.6, 20 screens, 4 flows, 8 access tiers, 24 releases, App Checker errors 329 → 3, 6 + 7 SharePoint lists, 561 tracked files). Before/after value cards, 6 benefit cards, 4 pure-CSS charts (binding errors by release, releases per month, repo composition donut, solution footprint), What's New in v1.3.5, a 6-step user journey, and a 6-image screenshot gallery.
- **Technical Implementation Guide:** architecture diagram and data-flow map, component inventory and versions, repository tree, 20-screen inventory, 8-tier access table, SharePoint data model, the 4 flows, connector matrix (no premium connectors), an 8-step import QuickStart with `pac` pack/unpack/export commands, ALM/CI workflows, and a security snapshot.
- **Roadmap, Governance & Evaluation:** development timeline, v1.3.5 known issues (KI-01/02/03/08/09/11/12), roadmap, evaluation checklist for a new facility, glossary, and a references/evidence map.
- All images and repo links use absolute public-mirror URLs (`raw.githubusercontent.com` / `github.com/KCoderVA/578-EHRM-TrainingBookingApp/blob/main/…`), so they still work when Pages publishes only `/docs`. All 24 linked paths were checked against `git ls-files`.

### New `docs/.nojekyll`
- Empty marker so GitHub Pages serves `/docs` as static files and skips Jekyll/Liquid processing (the release-note templates contain `{{…}}` placeholders).
