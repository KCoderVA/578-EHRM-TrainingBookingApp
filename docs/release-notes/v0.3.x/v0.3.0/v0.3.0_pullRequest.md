# PR: v0.3.0 — GitHub Actions/workflows overhaul, VERSION file, repo automation

## Summary

This PR prepares the **EHRM Training & Booking App** repo for the **v0.3.0** release by overhauling the GitHub Actions/workflows suite from disabled stubs into a fully functional CI/CD automation layer tailored for a solo-developer Power Platform project.

## Changes at a glance

| Area | What changed |
|------|--------------|
| `VERSION` | New file — single source of truth for SemVer (`0.3.0`) |
| `.github/labeler.yml` | Moved from `workflows/` to correct location; added `scripts` and `release` labels |
| `.github/PULL_REQUEST_TEMPLATE.md` | Moved from `ISSUE_TEMPLATE/` to correct location |
| `pr-auto-setup.yml` | **New** — auto-assign, contextual checklist, Copilot review request |
| `version-bump.yml` | **New** — one-click version scaffolding from Actions tab |
| `repo-lint.yml` | **New** — structure validation, JSON integrity, file placement checks |
| `pr-security-scan.yml` | **New** — PII/environment value scanning (GUIDs, URLs, emails, SSNs) |
| `release.yml` | **New** — auto-create GitHub Releases on `v*` tag push |
| `label.yml` | Enhanced — upgraded to actions/labeler@v5, added event types |
| `powerplatform-ci.yml` | Enhanced — Canvas/flow JSON validation, fixed solution path, added PR trigger |
| `stale.yml` | Enhanced — 90-day window, weekly schedule, exempt labels, upgraded to actions/stale@v9 |
| `greetings.yml` | **Removed** — no value for solo developer |
| `summary.yml` | **Removed** — requires GitHub Models, low value for solo dev |
| `CHANGELOG.md` | Added v0.3.0 entry |
| `README.md` | Version badge → v0.3.0 |
| `docs/PROJECT_STATUS.md` | Status summary → v0.3.0, added release history row |
| All `.yml` files | Added comprehensive educational comment headers and inline annotations |
