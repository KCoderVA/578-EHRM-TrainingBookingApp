feat(release): v0.3.0 — GitHub Actions/workflows overhaul, VERSION file, repo automation

## Context

This change set prepares the **EHRM Training & Booking App** repository for the **v0.3.0** release.

The repository previously had 5 GitHub Actions workflows that were all disabled (with `if: ${{ false }}` guards) since 2026-05-28. This release re-enables, fixes, enhances, and expands the workflow suite to provide meaningful CI/CD automation for a solo-developer Power Platform project.

## What changed

### New files

- `VERSION` — single source of truth for the project-wide SemVer version number
- `.github/labeler.yml` — label-to-path mapping config (moved from wrong location)
- `.github/workflows/pr-auto-setup.yml` — auto-assign PRs, contextual checklist, Copilot review
- `.github/workflows/version-bump.yml` — one-click version scaffolding from the Actions tab
- `.github/workflows/repo-lint.yml` — repo structure validation (required files, JSON integrity, file placement)
- `.github/workflows/pr-security-scan.yml` — PII/environment value scanning on PRs
- `.github/workflows/release.yml` — auto-create GitHub Releases on tag push
- `docs/release-notes/v0.3.x/v0.3.0/` — release artifacts (commit, PR, release notes)

### Enhanced files

- `.github/workflows/label.yml` — upgraded actions/labeler v4→v5, added event types
- `.github/workflows/powerplatform-ci.yml` — added Canvas/flow JSON validation, fixed solution path, added PR trigger
- `.github/workflows/stale.yml` — tuned for solo dev (90-day stale, weekly, exempt labels), upgraded actions/stale v5→v9
- All workflow files — added comprehensive educational comment headers and inline annotations

### Removed files

- `.github/workflows/greetings.yml` — no value for solo developer
- `.github/workflows/summary.yml` — requires GitHub Models, summarizes your own issues

### Fixed files

- `.github/labeler.yml` — moved from `.github/workflows/` to `.github/` (correct location)
- `.github/PULL_REQUEST_TEMPLATE.md` — moved from `.github/ISSUE_TEMPLATE/` to `.github/`
- `powerplatform-ci.yml` — fixed solution path from `src/solutions/` to `config/solutions/`

### Updated for v0.3.0

- `VERSION` — 0.3.0
- `README.md` — version badge and current version
- `CHANGELOG.md` — v0.3.0 entry
- `docs/PROJECT_STATUS.md` — status summary and release history table

### Notes

- Canvas app baseline remains v0.0.2
- `AppUserList` flow baseline remains v0.1.0
