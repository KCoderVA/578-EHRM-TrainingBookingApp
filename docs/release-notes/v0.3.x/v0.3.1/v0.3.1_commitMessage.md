feat(scripts): v0.3.1 — add Power Apps web development helper script

## Context

This change set prepares the **EHRM Training & Booking App** repository for the **v0.3.1** patch release.

## What changed

### New file

- `src/scripts/pwsh/powerapps-web.ps1` — PowerShell helper script for web-based Power Apps development workflow. Provides commands for:
  - `package` — pack unpacked source into .msapp for web upload
  - `open-portal` — open Power Apps maker portal in browser
  - `open-source` — open unpacked source folder in VS Code
  - `status` — show development environment status (source files, .msapp artifacts, PAC CLI)
  - `help` — display usage information
