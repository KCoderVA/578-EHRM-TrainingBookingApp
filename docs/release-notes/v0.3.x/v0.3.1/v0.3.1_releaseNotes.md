# EHRM Training & Booking App — Release Notes (v0.3.1)

- **Release date**: 2026-07-07
- **Release type**: Patch (developer tooling)
- **Previous release**: v0.3.0 (2026-07-07)

## Executive summary

v0.3.1 adds a PowerShell helper script for web-based Power Apps development. The script provides quick commands for packaging unpacked source into .msapp files, opening the Power Apps maker portal, and checking development environment status.

No functional changes to the Power Apps Canvas app or Power Automate flow logic.

## Changes

### Added

- `src/scripts/pwsh/powerapps-web.ps1` — Power Apps web development workflow helper with 5 commands: `package`, `open-portal`, `open-source`, `status`, `help`

## Component baselines (unchanged)

- Canvas app: v0.0.2
- `AppUserList` flow: v0.1.0
