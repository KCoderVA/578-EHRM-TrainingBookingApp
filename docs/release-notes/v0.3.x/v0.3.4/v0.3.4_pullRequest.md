## Canvas app changes — detailed breakdown

### 1. Role-Based Access Control (Dashboard)

`Dashboard.OnVisible` was completely refactored from a binary admin check into a full 8-tier RBAC system driven by `DeskAccessControl.AccessLevel_Text`. The app now enforces distinct menu access for: `SuperUser`, `AppAdmin`, `Manager`, `ServiceChief`, `ProjectLeader`, `User`, `View-only`, and `AccessDenied`.

> **Admin action required before deploying:** Ensure every user in `DeskAccessControl` has `AccessLevel_Text` populated. Users without a matching row will receive an empty menu (AccessDenied behavior).

### 2. Intelligent Scheduling (chkWeekDays)

- Auto-calculates default start time rounded up to nearest 15-minute boundary
- Pre-populates end time as start + 60 minutes
- New Importance, Reminder, and Event Recurrence dropdowns
- Live conflict detector shows existing bookings on the selected date
- Booking horizon extended 180 → 230 days

### 3. Appointment Management (MyAppts)

- Explicit "View This" (green) and "Cancel This" (red) buttons added to upcoming gallery
- Cancellation confirmation modal (NEVERMIND / CONFIRM) prevents accidental deletions
- Past filter expanded to catch deactivated/blank-Active_choice records

### 4. Reservation Detail Enhancements (Reservation + Confirm)

- Screen title "Reservation" → "Reservation Details"; all field labels clarified
- Confirm screen: Container grid, gallery template size 22→175px, combined training + location summary text

### 5. Calendar Modernization (scrn_DailyCal + scrn_WeeklyCal + scrn_MoCalendar)

- `scrn_WeeklyCal_1` removed; replaced by new `scrn_DailyCal` ("Daily Training Room List") with 6×6 grid layout
- `scrn_WeeklyCal` and `scrn_MoCalendar` containers upgraded to 6×6 grid layout
- All navigation references updated to `scrn_DailyCal`

### 6. App Version Variable (App.OnStart)

- `Set(varGetRepo_ProjectVersion, "0.3.4")` added to `App.OnStart` (previously empty)
- Version string displayed in Dashboard top-left corner

### 7. Connector Updates

- Added O365 Users actions: `MyProfileV2`, `ManagerV2`, `UserProfileV2`
- Removed deprecated Outlook actions: `V4CalendarGetItems`, `CalendarGetTables_V2`
- Connector icon CDN migrated to `gov.static.powerapps.us`
- Platform format: `FormatVersion` 0.24→0.30, `DocVersion` 1.347→1.349

### 8. Screenshots

- 19 screenshots captured 2026-07-09 from the live v0.3.4 app; all renamed to `v0.3.4_*` prefix

### 9. Solution Manifest Correction (src/solution.xml)

The `src/solution.xml` file contained identity and component data from an entirely unrelated project (Employee Recognition Solution), copy-pasted without modification. All content has been corrected to match the EHRM Training & Booking App:

| Element | Before (wrong) | After (correct) |

| `generatedBy` | `EmployeeRecognition` | `EHRMTrainingBooking` |
| `<UniqueName>` | `EmployeeRecognitionSolution` | `EHRMTrainingBooking` |
| `<LocalizedName>` | `Employee Recognition Solution` | `578 EHRM Training & Booking App` |
| `<Description>` | Employee Recognition narrative (v1.2.3) | EHRM Training & Booking narrative (v0.3.4) |
