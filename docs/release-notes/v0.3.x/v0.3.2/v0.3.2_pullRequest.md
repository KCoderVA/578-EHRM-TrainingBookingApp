# PR: v0.3.2 — GHES compatibility fixes for release and version-bump workflows

## Summary

This PR fixes GHES (GitHub Enterprise Server) compatibility issues in workflows that haven't been live-tested yet. Without these fixes, `release.yml` would fail on the first tag push and `version-bump.yml` would fail on first use from the Actions tab.

## Changes at a glance

| Area | What changed |
|------|--------------|
| `release.yml` | Added `GH_HOST` + `--repo` to both `gh release create` steps |
| `version-bump.yml` | Added `GH_HOST` + `--repo` to `gh pr create` step |
| `pr-auto-setup.yml` | Disabled Copilot review job (not available on GHES) |
| `VERSION` | 0.3.1 → 0.3.2 |
| `CHANGELOG.md` | Added v0.3.2 entry |
| `README.md` | Version badge → v0.3.2 |
| `docs/PROJECT_STATUS.md` | Status summary → v0.3.2, added release history row |
| Release docs | Added `docs/release-notes/v0.3.x/v0.3.2/` |
