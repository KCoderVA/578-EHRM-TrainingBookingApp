# EHRM Training & Booking App — Release Notes (v0.3.2)

- **Release date**: 2026-07-07
- **Release type**: Patch (GHES workflow compatibility fixes)
- **Previous release**: v0.3.1 (2026-07-07)

## Executive summary

v0.3.2 fixes GHES (GitHub Enterprise Server) compatibility issues in the `release.yml` and `version-bump.yml` workflows that were introduced in v0.3.0 but not yet live-tested. Without these fixes, pushing a version tag or using the version-bump workflow from the Actions tab would fail with `HTTP 401: Bad credentials` because the `gh` CLI defaults to `api.github.com` instead of `va.ghe.com`. This release also disables the Copilot code review job in `pr-auto-setup.yml` since Copilot review is not available on GHES, eliminating a misleading red X on every PR.

## Changes

### Fixed

- `release.yml` — added `GH_HOST: va.ghe.com` and `--repo` flag to both `gh release create` steps
- `version-bump.yml` — added `GH_HOST: va.ghe.com` and `--repo` flag to the `gh pr create` step
- `pr-auto-setup.yml` — commented out the Copilot review job with re-enable instructions for when Copilot review becomes available on GHES

## Component baselines (unchanged)

- Canvas app: v0.0.2
- `AppUserList` flow: v0.1.0
