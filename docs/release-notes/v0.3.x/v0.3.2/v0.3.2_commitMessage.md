fix(ci): v0.3.2 — GHES compatibility fixes for release and version-bump workflows

## Context

This change set prepares the **EHRM Training & Booking App** repository for the **v0.3.2** patch release.

During live testing of the v0.3.0 and v0.3.1 releases, several workflows failed because the `gh` CLI defaults to `api.github.com` when no git repo context is available. Since this repository is hosted on GitHub Enterprise Server (`va.ghe.com`), all `gh` CLI calls need explicit `GH_HOST` and `--repo` parameters.

## What changed

### Fixed

- `release.yml` — added `GH_HOST` and `--repo` to both `gh release create` steps (would have 401'd on first `v*` tag push)
- `version-bump.yml` — added `GH_HOST` and `--repo` to the `gh pr create` step (would have 401'd on first version bump)
- `pr-auto-setup.yml` — disabled the Copilot review job (not available on GHES; was producing a misleading red X failure on every PR)

- `VERSION` — 0.3.2
- `README.md` — version badge and current version
- `CHANGELOG.md` — v0.3.2 entry
- `docs/PROJECT_STATUS.md` — status summary and release history table
