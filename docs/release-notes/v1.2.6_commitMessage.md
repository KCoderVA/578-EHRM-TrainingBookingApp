fix(canvas-app): v1.2.6 — update DebuggingScreen height and automate coauthoring release workflow

## Context

This commit releases the **578 EHRM Training App v1.2.6** maintenance update. The connected Canvas app was changed through the live coauthoring workflow, compiled through the Power Apps authoring service, and independently re-synchronized to verify that the server-side session retained both edits.

The Canvas app component advances from v1.2.4 to v1.2.6 to align with the latest concurrent project version, while the repository release version advances from v1.1.20 to v1.2.6.

---

## What changed — Canvas app

### DebuggingScreen

- Changed the screen-level `Height` formula from `App.Height` to `App.Height + 1`.
- The one-pixel adjustment is intentionally small and serves as a controlled proof that Copilot CLI can modify and verify the connected coauthoring session.

### App.OnStart

- Changed `Set(varRepoVersion, "1.2.4")` to `Set(varRepoVersion, "1.2.6")`.
- A fresh `sync_canvas` confirmed the new version assignment after `compile_canvas`.

### Validation

- Canvas compile diagnostics remained unchanged at 15 errors and 119 warnings.
- No compile diagnostic referenced the modified `DebuggingScreen.Height` property or the active `varRepoVersion` assignment.
- Existing app-checker and accessibility findings were recorded as baseline issues and were not changed by this release.
