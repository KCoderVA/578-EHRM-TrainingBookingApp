## Canvas app changes — detailed breakdown

### 1. App-wide Role-Based Access Control engine

Access resolution moved from `Dashboard.OnVisible` into `App.OnStart`, so it runs once per session and gates every screen. Eight tiers (`AccessDenied` → `View-only` → `User` → `SuperUser` → `Manager` → `ServiceChief` → `ProjectLeader` → `AppAdmin`) are read live from `DeskAccessControl.AccessLevel_Text` and wired into the navigation menu (`colMenu`), Dashboard messaging, calendar `DisplayMode`/`Items` filters, and admin-only controls.

> **Admin action required before deploying:** populate `DeskAccessControl.AccessLevel_Text` for all intended users, and decide the unknown-user default (currently `User`; `AccessDenied` recommended).

### 2. Impersonation ("act as another user")

Admins get a hidden Dashboard combobox that re-renders the entire app as any selected user — for support/troubleshooting and booking on behalf of others.

- The real signed-in identity is captured separately and cannot be spoofed.
- Auto-provisioning only ever writes for the real user, never while impersonating.

### 3. Zero-touch user onboarding

First-launch users with no `DeskAccessControl` row are auto-provisioned at default `"User"` level (Entra ID, timestamps, manager email via `Office365Users.Manager`), then re-read.

### 4. Training Class/Session Picker

New `ctn_PopUp_ClassPicker` popup on `POCSUPERVISOR` (Scenario → Role → Date/Time session → Location), deep-linking into the SharePoint Learning Lab Workbook library, with selections echoed on Confirm.

### 5. New `alt_ManageDesks` screen + supporting redesigns

- `alt_ManageDesks` — modern responsive CRUD console for the `Desks` list (22 screens total).
- Dashboard redesign (theme, mascot banner, role-aware messaging, version timer).
- Calendar and `chkWeekDays` layout/visibility refinements; assets 6 → 38; new `Tabs_altColor` component.
- Data sources and connections unchanged.
