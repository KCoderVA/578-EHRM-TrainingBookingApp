## Changes — detailed breakdown

### 1. App branding & UI assets (`assets/images/`)

21 image files committed for the first time, covering the full visual asset library: a site theme banner, a people/staff banner, 3 UI button graphics, 9 icon images (including silhouette role icons and feature icons), 1 super-user role image, and 6 mascot variants (banner, icon horizontal/round/vertical/low-res, all in various backgrounds). These assets back the Canvas app's visual design and are now tracked in source control alongside all other app artifacts.

### 2. Developer backup tooling (`src/scripts/pwsh/backupProject.ps1`)

New PowerShell 7 script that creates a timestamped ZIP archive of the entire workspace to `archive/backup/` (git-ignored). Process: compress workspace to `$env:TEMP` → run `7z t` integrity check → move to permanent `archive/backup/` path → re-run `7z t` integrity check → report success/failure with full archive path. Auto-detects project root whether invoked from within `src/scripts/pwsh/` or from the workspace root.

### 3. Release artifact rotation (`docs/release-notes/`)

Standard end-of-cycle rotation: v0.3.6 release artifacts (`v0.3.6_commitMessage.md`, `v0.3.6_pullRequest.md`, `v0.3.6_releaseNotes.md`) removed from the live `docs/release-notes/` folder. Replaced by freshly populated v0.3.7 equivalents plus `v0.3.7_priorityWorklist.md` — a comprehensive Canvas app, security, and repository improvement plan generated during the 2026-07-14 project deep-dive.

### 4. Enterprise script relocation (`src/scripts/pwsh/` → `releaseTemplates/`)

`enterpriseCommitGuide.ps1` and `postEnterpriseCommitArchival.ps1` were previously tracked under `src/scripts/pwsh/` (added in v0.3.5). These are release-cycle orchestration helpers — not source-control automation scripts — and are best co-located with the release artifact templates they operate on. They have been removed from tracked source and relocated locally to `docs/release-notes/releaseTemplates/` (git-ignored per `.gitignore`).
