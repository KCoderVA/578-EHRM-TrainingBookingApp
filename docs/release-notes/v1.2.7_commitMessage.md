feat(power-automate): v1.2.7 - add automated TMS report ingestion for SharePoint and Power BI

## Context

This commit prepares the **578 EHRM Training App** repository for the v1.2.7 feature release. It adds
the newly exported `578EHRMTrainingApp_parseTMSReport-updateSharePointCSV` cloud flow, documents its
source-level behavior and operating requirements, and connects the Power Automate and analytics
documentation around the canonical TMS CSV used by the internal Power BI report.

The new flow component starts at v1.0.0; the project-wide version advances from v1.2.6 to v1.2.7.
The Canvas app remains on its v1.2.6 coauthoring baseline.

---

## What changed - Power Automate

### New `parseTMSReportsToSharePoint` flow

- Added legacy-package source under `src/powerAutomate/parseTMSReportsToSharePoint/.unpacked/`.
- Monitors attachment-bearing Outlook messages from the configured TMS reporting sender.
- Retrieves lowercase `.csv` attachments and overwrites the secured SharePoint
  `TMS_Reports/TMSProgramCompletion_DetailedReport.csv` file.
- Attempts to create a dated copy in `TMS_Reports/archives` for each accepted attachment.
- Uses Office 365 Outlook and SharePoint Online embedded connections.

### Source analysis and documentation

- Added `src/powerAutomate/parseTMSReportsToSharePoint/README.md` with the trigger, action inventory,
  connection requirements, SharePoint/Power BI contract, deployment steps, tests, and security notes.
- Added `v1.2.7_flowAnalysis.md` with control-flow findings and a prioritized hardening backlog.
- Clarified that SharePoint receives the original attachment bytes. The current Compose/Select branch
  extracts `Program ID` only into unused transient outputs and does not transform the Power BI source.
- Documented that Power BI refresh remains separately scheduled and is not invoked by this flow.

### Known follow-ups

- Validate the exact report subject and filename before allowing a CSV to replace the production source.
- Move attachment-dependent parsing inside the CSV condition and normalize uppercase extensions.
- Replace raw `utcNow()` archive names with a SharePoint-safe timestamp.
- Add explicit failure notification and decide whether to complete or remove the unused parsing branch.
