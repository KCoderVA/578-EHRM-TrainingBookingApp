This commit delivers the **EHRM Training & Booking App** repo with the **v0.8.16** feature release — the first major Canvas app functional advance imported into source control since v0.3.4. The updated `.msapp` package (`v0.8.14_578EHRMTrainingApp.msapp`) was unpacked via `pac canvas unpack` and the resulting source files under `./src/powerApps/.unpacked/` now reflect the v0.8.14 state. The Canvas app component version advances from v0.3.4 → v0.8.14, and the project-wide version jumps 0.3.8 → 0.8.16 to bring the repository release line onto the Canvas app's independently-advancing `0.8.x` series.

## What changed — Canvas app v0.8.14 (src/powerApps/.unpacked/)

### Screen additions
- `Src/alt_ManageDesks.fx.yaml` — **NEW** modern responsive-layout CRUD console (~510 KB) for the `Desks` list (add/edit/delete via NewForm/Patch/Remove); staged alongside legacy `ManageDesks`. App now has 22 screens (was 21).

### App.fx.yaml / OnStart (app-wide RBAC engine)
- `App.OnStart` grew from a 1-line version stub (966 bytes) into a full RBAC + auto-provisioning + impersonation engine (6,433 bytes).
- Eight access tiers read live per-user from `DeskAccessControl.AccessLevel_Text` into `userAccessLevel_text` (+ `user_isAdmin`): AccessDenied → View-only → User → SuperUser → Manager → ServiceChief → ProjectLeader → AppAdmin.
- Dynamic navigation menu (`colMenu`) moved out of `Dashboard.OnVisible` into `App.OnStart` so gating applies consistently across all screens.
- Zero-touch onboarding: first-launch users with no access row are auto-Patched at default `"User"` level (Entra ID, timestamps, manager email via `Office365Users.Manager`), then re-read. Auto-provision writes only for the real user, never while impersonating.

### POCSUPERVISOR.fx.yaml (Class/Session Picker)
- Added `ctn_PopUp_ClassPicker` popup (+75,468 bytes, largest screen change): Scenario → Role → Date/Time session → Location, captured into `varPopUp_ClassPicker_*`; deep-links into the SharePoint Learning Lab Workbook library; selections echoed on Confirm.

### Dashboard.fx.yaml (redesign + impersonation)
- Dark-navy theme, mascot banner, role-aware welcome / "ACCESS DENIED" / "VIEW ONLY" messaging, author/version timer.
- Added hidden admin combobox + status button to impersonate any user (re-resolves target email/access record/level/profile, rebuilds menu).

### Calendar & chkWeekDays refinements
- `scrn_MoCalendar`, `scrn_WeeklyCal`, `scrn_DailyCal` — layout/visibility polish; per-role `DisplayMode` and `Items` filtering.
- `chkWeekDays.fx.yaml` — loose top-level controls consolidated under group containers.

### Assets & components
- Image assets grew from 6 → 38; added `Tabs_altColor` component.
- Data sources and connections unchanged (no SharePoint schema or connector changes at the app-manifest level).
