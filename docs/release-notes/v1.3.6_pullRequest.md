# PR: v1.3.6 — Docs: GitHub Pages project overview (docs/index.html), .nojekyll, version and documentation alignment

## PR Summary

This PR delivers the **v1.3.6** documentation patch for the **578 EHRM Training App** repo. It adds a graphical, self-contained GitHub Pages overview (`docs/index.html`) so leaders and developers at other VA facilities can see what the solution does and how to import it. The page was modeled on the Telehealth Schedule & Booking project's overview page. Every metric on it comes from the repository. No Canvas app, flow, SharePoint, or analytics source changed. All project documentation was updated for the new version.

All component versions are unchanged (Canvas app v1.3.5, flows, SharePoint v1.0.12, `src/solution.xml` v1.3.5).

## Documentation changes — detailed breakdown

### 1. Executive Overview chapter (for leadership)

Explains the EHRM training scheduling problem and the solution in plain language, with emphasis on **no new cost** (standard M365 connectors only), security, coordinator time saved, and leadership visibility.
- **8 KPI tiles:** v1.3.6, 20 screens, 4 flows, 8 access tiers, 24 releases, App Checker errors 329 → 3, 6 + 7 SharePoint lists, 561 tracked files / 76 commits.
- **4 pure-CSS charts:** binding errors by release, releases per month, repository composition donut, solution footprint.
- Before/after and benefit cards, What's New in v1.3.5, a 6-step user journey, and a 6-image screenshot gallery from the in-app guide.

### 2. Technical Implementation Guide chapter (for developers/analysts)

- Architecture diagram and text data-flow map (app → SharePoint/Outlook → flows → Power BI).
- Tables: components and versions, repository tree, 20 screens grouped by area, 8-tier access matrix, SharePoint data model (6 app lists, national read-only lists, TMS CSV), the 4 flows (trigger, action, connectors), connector matrix.
- **Deployment QuickStart:** prerequisites, 8 import steps, `pac canvas pack/unpack` and `pac solution export/unpack` commands, and a warning to replace environment-specific values.
- ALM/versioning summary, the `.github/workflows/` inventory, and a security/privacy snapshot.

### 3. Roadmap, Governance & Evaluation chapter

Development timeline (v0.0.1 → v1.3.6, go-live highlighted), v1.3.5 known issues, roadmap, evaluation checklist for a new facility, glossary, and a references/evidence map that links each topic to its source document.

### 4. Hosting and portability

- Pages from a `/docs` source publishes only that folder, so every image and repo link uses absolute public-mirror URLs. All 24 linked paths were checked against `git ls-files` (case-exact).
- `docs/.nojekyll` turns off Jekyll so Markdown under `docs/` (including `{{…}}` placeholder templates) cannot break the Pages build.
- No external scripts, fonts, or CDNs, so the page works on restricted VA networks. Accessibility: skip link, ARIA labels on charts, high-contrast mode, `prefers-reduced-motion` support, 44 px tap targets.

> **Admin action required after merge (public mirror):** *Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/docs`*. Expected URL: `https://kcoderva.github.io/578-EHRM-TrainingBookingApp/`.
