feat(release): v1.0.12 — production go-live; RBAC hardening, proxy registration, new CreateBackups flow, docs overhaul

## Context

This commit delivers the **578-EHRM-TrainingSchedulerApp** repo's **v1.0.12** production go-live release —
the first `1.x` line, aligning the repository with the app that is now live to ~100–150 hospital staff.
The Canvas app was developed hands-on in the Power Apps (US Gov) editor and re-exported; the packaged
`.msapp` (`v1.0.12_578EHRMTrainingApp.msapp`) was unpacked via `pac canvas unpack` into
`src/powerApps/.unpacked/`, the two new/updated flows were unpacked into `src/powerAutomate/*/.unpacked/`,
and the Power BI reports + SharePoint reference data were staged under `src/`.

The Canvas app component advances from v0.12.2 → v1.0.12 (public). Project
`VERSION` jumps `0.12.4 → 1.0.12` (the interim 0.12.4 was never shipped).

## What changed — Canvas app (src/powerApps/)

### Screen removals
- `Src/CreateMeeting.fx.yaml` — **REMOVED** (dead Microsoft "Meeting Scheduler" template; not in booking flow).
- `Src/Screen3.fx.yaml` — **REMOVED**, superseded by `scrn_MoCalendar`/`scrn_WeeklyCal`/`scrn_DailyCal`.

### Screen additions
- `Src/Screen1.fx.yaml` — **NEW** A4-landscape printable Power BI embed (GOV cloud); not yet in menu.

### App.fx.yaml / OnStart
- Removed hard-coded impersonation backdoor → `Set(varRealEmail, Lower(User().Email))`.
- RBAC "default to `User` first" with self-provisioning `Patch` (6-month window); removed `AccessDenied` race.
- `Learning Lab Sessions` now `Filter(..., Facility.Value = "Hines")`; `varRepoVersion` 0.12.2 → 1.0.12.
- Enabled modern controls via `Host As hostControl.DefaultHostControlVariant`.

### Confirm.fx.yaml / POCSUPERVISOR.fx.yaml
- Single-student **proxy registration**; `dropdown_Role/Scenario/DateTime/LocationPicker`; Learning Labs
  Library class picker; `V4CalendarPostItem`; hardened `Patch` with `IsBlankOrError` fallbacks.

### Components
- `Tabs`/`Tabs_3` empty-menu `TemplateSize` guard; `Tabs_3` width `&`→`*`; `Calendar` `#0707077`→`#070707`.
