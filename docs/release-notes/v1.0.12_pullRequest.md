## Detailed breakdown

### 1. Security — impersonation backdoor removed
`App.OnStart` no longer spoofs the developer's identity to another user; it uses the real signed-in
identity, retaining only a controlled proxy path for register-on-behalf.

### 2. RBAC hardening
Default-to-`User` baseline before any SharePoint dependency; new users self-provision a 6-month access row;
the former new-user `AccessDenied` race is eliminated.

### 3. Proxy registration + Learning Labs Library class picker
`POCSUPERVISOR`/`Confirm` converted to single-student proxy registration with structured pickers and a
read-only national **Learning Labs Library** class/scenario picker; Outlook invite upgraded to
`V4CalendarPostItem`.

> **Admin action required before deploying:** grant the target environment read access to the national
> `vacoehrmioeue/Sandbox` lists/library (or substitute your own), and re-point all SharePoint data sources
> and flow `dataset`/`table` references to your site + list GUIDs.

### 4. Automation
- **New `CreateBackups`** flow writes a backup reservation from the app's confirmation email.
- `SendReminders` adds Teams adaptive cards, gates email behind a `CreatedBy` condition, and slows polling 1 → 5 min.

### 5. SharePoint & Analytics
National EHRM Sandbox reference lists integrated; new `SuperUserDashboard-Final` PBI report + `tms/` TMS
data staging.

### 6. Reliability & cleanup
Binding errors **120 → 0**; two dead screens removed (21 → 20); partial classic → modern control migration.
