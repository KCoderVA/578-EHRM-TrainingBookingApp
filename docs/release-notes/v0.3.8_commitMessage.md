chore(sharepoint,analytics,repo): v0.3.8 — SharePoint list restructuring, new Analytics component, .gitignore local-folder hardening, documentation catch-up

## Context

This commit prepares the **EHRM Training & Booking App** repository for the **v0.3.8** maintenance release — a repository reorganization and documentation-catch-up pass, with no functional Canvas app or Power Automate changes. The changes were made directly in the local workspace (no `pac` export/unpack this cycle): a new `src/analytics/` component was created for Power BI/SQL reporting assets, the `src/sharePoint/` component was restructured from a flat per-list sample layout into a `list/<listName>/local/` + `searchConfig/` structure, two new branding images were added, and `.gitignore` was hardened to close a gap that left a large local screen recording completely untracked by any ignore rule. All root and component documentation (`README.md`, `CHANGELOG.md`, `docs/PROJECT_STATUS.md`, `.github/copilot-instructions.md`) was updated to match.

---

## What changed — SharePoint (`src/sharePoint/`)

- Replaced the flat per-list sample layout (`Desk Reservations/`, `DeskAccessControl/`, `Desks/`) with a `list/<listName>/local/` structure: `list/deskAccessControl/`, `list/deskReservations/`, `list/desks/`, plus a new `list/schedule/` scaffold — a 4th list with no schema exported yet, staged from `SULL_Jesse_Brown_Schedule_7.10.26 - Integrated.xlsx` in support of the ongoing "desk reservation" → "training booking" terminology migration.
- Added `searchConfig/SearchConfiguration.xml` — first tracked SharePoint search configuration export.
- Added `src/sharePoint/README.md` documenting the new structure, a list status table, and the provenance of the prior layout (archived locally to `archive/src/sharePoint/`).
- Confirmed via `git ls-files` that the sanitized CSVs previously tracked at the old flat paths (flagged as "pending cleanup" since the v0.3.6 changelog entry) have already been untracked — no `git rm --cached` action remains outstanding.

## What changed — Analytics (`src/analytics/`) — NEW component

- Added `src/analytics/powerBI/.pbit/Signup Tool.pbit` — first tracked Power BI report template.
- Scaffolded `src/analytics/powerBI/.pbix/`, `src/analytics/powerBI/local/`, `src/analytics/sql/procedures/`, `src/analytics/sql/queries/`, `src/analytics/sql/local/` (currently empty).
- Added `src/analytics/README.md` documenting the structure and early-stage status.
- Replaces the previously-aspirational, never-populated flat `src/powerBI/` and `src/sql/` component descriptions in `copilot-instructions.md` (see `docs/release-notes/v0.3.7_priorityWorklist.md` §5.2).
