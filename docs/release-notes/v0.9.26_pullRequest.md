# PR: v0.9.26 — Power Apps: persist full training records, expand Desk Reservations schema, rework POCSUPERVISOR

## PR Summary

This PR delivers the **v0.9.26** feature release of the **578-EHRM-TrainingSchedulerApp**. Where v0.8.14 was about *access*, v0.9.26 is about *data*: every booking is now saved as a complete, attributable **training registration record**. The Canvas app was updated hands-on in the Power Apps editor, re-exported as `v0.9.26_578EHRMTrainingApp.msapp`, and unpacked into `./src/powerApps/.unpacked/` via `pac canvas unpack`. All project documentation has been updated end-to-end.

The Canvas app component advances **v0.8.14 → v0.9.26**. The project-wide version jumps **`0.8.16 → 0.9.26`** to re-align the repo release line with the Canvas app, **superseding the never-completed `0.8.17`** cycle (its blank release-note stubs were renamed/refilled as `v0.9.26_*`).

## Canvas app changes — detailed breakdown

### 1. `Desk Reservations` schema expansion — a booking is now a full training record

~40 columns were added, grouped into **submitter**, **student/attendee** (incl. manager email), **reservation detail** (scenario / role / session start-end / decomposed location), **narrative bodies**, **trainer approval** (received → approved → recorded-in-Excel), and **automated reminders** (1 week / 72 h / 1 h pre-class + 24 h post-create). Legacy `DeskFloor`, `Floor`, `Reason for desk reservation` were removed.

> **Admin action required before deploying:** the SharePoint list must actually contain these columns (matching internal names) before the SUBMIT `Patch` will succeed; and the companion Power Automate flows that populate the `trainer*`/`reminder*` columns (written blank by the app) and create the Outlook invite must be built.

### 2. Class/Session Picker persistence (Confirm SUBMIT) — closes the v0.8.14 gap

The SUBMIT `Patch` now writes submitter identity, student identity, scenario/role, session start/end, decomposed location, and invite/agreement bodies, plus a structured `Title`. `OutlookEventID`/`OutlookSeriesID` are deferred to a flow.

### 3. Booking on behalf of others

A new attendee people-picker (`var_Attendees`) records the **submitter** (real signed-in user) and the **student** (chosen attendee) as distinct identities.

### 4. POCSUPERVISOR rework + `Desks` normalization + fixes

Semantic picker control names, live selection summary, scenario-materials deep-link, admin RESET; `Desks` normalized and screens re-bound; `varRepoVersion → 0.9.26`; `varIsImpersonating` corrected; `modernText`/`modernTextInput` templates added.
