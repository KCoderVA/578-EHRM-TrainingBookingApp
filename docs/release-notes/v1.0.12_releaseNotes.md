- **Release date**: 2026-08-25

## Executive Summary

v1.0.12 is the first production release line of the EHRM Training & Booking App, documenting the jump from
the pre-release `0.12.x` line to the live `1.x` product used by ~100–150 staff at Edward Hines Jr. VA
Hospital. This is a broad **functional + security + reliability** release: it removes a developer
impersonation backdoor, hardens role-based access control, introduces proxy (register-on-behalf)
registration and a national-library-driven class picker, adds a new backup-reservation flow and Teams
reminders, expands the SharePoint reference-data surface, and adds a leadership Power BI dashboard — while
driving canvas binding errors from 120 to 0.

Seven distinct improvement areas are documented below:

1. **Security** — removed hard-coded impersonation backdoor.
2. **RBAC** — default-to-`User`, self-provisioning, race eliminated.
3. **Registration** — single-student proxy workflow + Learning Labs Library class picker.
4. **Automation** — new `CreateBackups` flow; `SendReminders` gains Teams cards.
5. **SharePoint** — national EHRM Sandbox reference lists/library integrated.
6. **Analytics** — new `SuperUserDashboard-Final` report + `tms/` data staging.
7. **Reliability/cleanup** — binding errors 120 → 0; two dead screens removed; modern-control migration begun.

## Changes

### Canvas app — Security: impersonation backdoor removed (`App.fx.yaml`)

Prior versions hard-coded a spoof so that the developer's sign-in resolved to another user's identity. v1.0.12
removes it entirely and uses the real signed-in identity, keeping a controlled proxy path for
register-on-behalf.

```powerfx
// OLD: If(Lower(User().Email)="kyle.coder@va.gov", Set(varRealEmail, Lower("Matthew.Olson@va.gov")), …)
// NEW:
Set(varRealEmail, Lower(User().Email));
Set(varTargetEmail, varRealEmail);
```

### Canvas app — RBAC hardened (`App.fx.yaml`)

Everyone with network access now starts at a safe `"User"` baseline; existing users are upgraded in-memory
and brand-new users are self-provisioned (6-month access window) without a blocking re-read.

| Tier | Applies to | Behavior |
|---|---|---|
| baseline | any authenticated user | `userAccessLevel_text = "User"` before any SharePoint dependency |
| existing | user in `DeskAccessControl` | `Coalesce(AccessLevel_Text, AccessLevel_Choice.Value, "User")` |
| new | first launch | fire-and-forget `Patch` with 6-month window + audit stamp |

### Canvas app — Proxy registration + class picker (`POCSUPERVISOR.fx.yaml`, `Confirm.fx.yaml`)

Converted from multi-attendee to single-student; selecting a student re-targets the SharePoint writes and
the Outlook invite. New `dropdown_RolePicker/ScenarioPicker/DateTimePicker/LocationPicker` and a class
picker backed by the read-only **Learning Labs Library**. `Confirm` upgrades the invite to
`Office365Outlook.V4CalendarPostItem` and sends `[REGISTERED] EHRM Learning Lab Training - …`.

### Power Automate — new `CreateBackups`; `SendReminders` gains Teams

`CreateBackups` triggers on the confirmation email above, parses it into ~19 Compose steps, enriches with
user/manager, and writes a backup reservation row. `SendReminders` now posts Teams adaptive cards, gates
email behind a `CreatedBy` rollout condition, and polls every 5 min (was 1 min).

### SharePoint — national EHRM Sandbox reference data

Reorganized into `nationalEHRM/sandbox/`; added tracked `.url` shortcuts for EHRM Roles, Scenario, Service
Line, Learning Lab Sessions/Signups, Scenario Workflows, plus the Learning Labs Library.

### Analytics — new dashboard + TMS staging

New `SuperUserDashboard-Final.pbix` (leadership dashboard on a published dataset; WIP) and a new `tms/`
folder staging VA TMS completion exports for reporting.

### Reliability & cleanup

Binding errors driven **120 → 0** (`IsBlankOrError` guards; `Tabs`/`Tabs_3` empty-menu guard; `Tabs_3`
`&`→`*` width fix; `Calendar` hex fix). Removed dead `CreateMeeting` and `Screen3` screens (21 → 20).

| Field | Before | After |
|---|---|---|
| Canvas binding errors | 120 | **0** |
| Screen count | 21 | **20** |
| Impersonation backdoor | present | **removed** |

### Documentation & Screenshots

## Known issues / follow-ups
- `SendReminders` email gate is **intentional** — reminders fire only for developer-created (`Kyle.Coder`) items; live end-user submissions behave differently by design.
- `ReleaseNotes` in-app screen content is stale; a proposed replacement is drafted at `src/powerApps/local/v1.1.0_proposedUpdatedReleaseNotes.yaml` for a future v1.1.0. `Screen1` (printable PBI) has no menu entry.
- The ~6.6 GB OneDrive export in `sharePoint/library/.../local/` is git-ignored and retained by design (developer-only).
