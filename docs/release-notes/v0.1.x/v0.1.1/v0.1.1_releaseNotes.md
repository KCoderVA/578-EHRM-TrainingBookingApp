# EHRM Training & Booking App — Release Notes (v0.1.1)

- **Release date**: 2026-05-28
- **Release type**: Maintenance (Public documentation + repository alignment)
- **Previous release**: v0.1.0 (2026-05-27)

## Executive summary

v0.1.1 is a documentation and repository-alignment release that prepares the project for public consumption.

The v0.1.1 “draft” commit/PR/release note files previously in this repo were copied from an unrelated project and still contained incorrect naming and version references. This release replaces those placeholders with accurate, project-specific documents and ensures the repository’s canonical paths and runbook references match the current workspace layout.

No functional changes are intended to the Power Apps Canvas app or Power Automate flow logic in this release.
