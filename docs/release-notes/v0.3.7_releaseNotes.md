## Executive Summary

v0.3.7 is a maintenance/patch release focused on repository asset additions, developer tooling, and ALM housekeeping. The most significant additions are a comprehensive set of 21 app branding and UI image assets committed to `assets/images/`, and a new `backupProject.ps1` PowerShell script that creates timestamped, 7-Zip-validated ZIP archives of the entire workspace. This release also completes the v0.3.6 → v0.3.7 artifact rotation cycle and relocates the two enterprise automation scripts from `src/scripts/pwsh/` into the `docs/release-notes/releaseTemplates/` folder (where they are git-ignored, per design). No functional changes were made to the Canvas app, Power Automate flows, or SharePoint schema.

4 distinct improvement areas are documented below:

1. **App branding & UI assets** — 21 new image files added to `assets/images/` (icons, buttons, mascots, banners)
2. **Developer backup tooling** — new `backupProject.ps1` script for timestamped workspace archival with 7z integrity validation
3. **Release artifact rotation** — v0.3.6 release artifacts removed; v0.3.7 stub artifacts created; priority worklist added
4. **Enterprise script relocation** — `enterpriseCommitGuide.ps1` and `postEnterpriseCommitArchival.ps1` moved from `src/scripts/pwsh/` to `docs/release-notes/releaseTemplates/` (git-ignored)

### Scripts — New Developer Backup Tool (`src/scripts/pwsh/backupProject.ps1`)

No automated local backup mechanism existed for the workspace prior to this release. Developers relied on manual copies or the git history, which does not capture git-ignored local-only content (e.g., `dist/`, `archive/`, `config/`). The new `backupProject.ps1` script addresses this gap.

**What it does:**

- Generates a timestamped filename (`YYYY.MM.DD-HH.mm.ss_GHEC-US-Repo.zip`) and stores the archive under `archive/backup/` (git-ignored).
- Compresses the entire project workspace to a temporary path in `$env:TEMP` first, then moves it to the permanent `archive/backup/` location after a 7-Zip integrity test (`7z t`).
- Validates archive integrity both in the temp location and again after the move to the permanent folder.
- Prints a clear success/failure summary with the full archive path.
- Auto-detects the project root path whether run from within `src/scripts/pwsh/` or from the workspace root.

## Known Issues

- **Canvas app RBAC default role** (tracked in `v0.3.7_priorityWorklist.md` §1.1): New unknown users are auto-granted `User` access instead of `AccessDenied`. This is a security gap to be fixed in an upcoming Canvas app update — it requires a Power Apps editor change, re-export, and re-unpack cycle. The app should not be promoted to broad production use until this is resolved.
- **Tracking cleanup pending** (from v0.3.6): The 3 `config/` files (`ARCHITECTURE.md`, `ALM-RUNBOOK.md`, `alm.ps1`) and 10 `src/sharePoint/*.csv` files remain in the git index and will continue to appear in remote repo history until `git rm --cached` is explicitly run. See worklist item 5.1 in `v0.3.7_priorityWorklist.md`.
