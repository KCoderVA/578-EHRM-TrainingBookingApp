feat(powerApps): v0.9.26 — persist full training records, expand Desk Reservations schema (+~40 cols), rework POCSUPERVISOR

## Context

This commit releases the **578-EHRM-TrainingSchedulerApp** repo with the **v0.9.26** feature release — the Canvas app now saves every booking as a complete, attributable training registration record instead of discarding the scenario/role/session/location the user picks. The Canvas app was updated hands-on in the Power Apps editor, re-exported as `v0.9.26_578EHRMTrainingApp.msapp`, and unpacked via `pac canvas unpack` into `./src/powerApps/.unpacked/`, which now reflects the v0.9.26 state.

The Canvas app component version advances from v0.8.14 → v0.9.26. The project-wide version jumps `0.8.16 → 0.9.26` to re-align the repo release line with the Canvas app, superseding the never-completed `0.8.17` bump.

---

## What changed — Canvas app (src/powerApps/)

### SharePoint data sources (Desk Reservations, Desks)
- `Desk Reservations` — **+~40 columns** added, grouped into `submitter*`, `student*`, `reservation*` (scenario/role/start/end/decomposed-location), narrative `*_multilinetext` bodies, `trainer*` approval, and `reminder*` tracking families. **Removed** legacy `DeskFloor`, `Floor`, `Reason for desk reservation`.
- `Desks` — normalized: legacy untyped/duplicate columns removed; typed `*_choice`/`*_text`/`*_boolean` retained; `Title` → `ItemID_title`.

### Confirm.fx.yaml (SUBMIT persistence)
- SUBMIT `Patch` rewritten to persist submitter identity (`Office365Users.MyProfileV2()`), student identity (`UserProfileV2`/`ManagerV2` of `var_Attendees`), scenario/role, `reservationStart_datetime`/`reservationEnd_datetime`, decomposed location, and invite/agreement bodies; structured `Title`; `varRecurrenceID = Max(existing)+1`.
- `OutlookEventID`/`OutlookSeriesID`/`ParentReservationID` inserted blank (deferred to a flow).

### POCSUPERVISOR.fx.yaml (+63 KB)
- Class/Session Picker reworked: dropdowns renamed `dropdown_ScenarioPicker`/`RolePicker`/`DateTimePicker`/`LocationPicker`; added attendee people-picker (`var_Attendees`) for booking-on-behalf; live HTML selection summary; scenario-materials deep-link; admin `RESET` (`Button1`).

### Reservation.fx.yaml (+6 KB)
- Surfaces `reservationScenario_text`, `reservationRole_text`, `reservationStart_datetime`, `submitterName_text`; adds "Contact the EHRM Trainers about this item (#ID)" action.

### App.fx.yaml
- `varRepoVersion` "0.8.12" → "0.9.26"; `varIsImpersonating` corrected to `varRealEmail <> varTargetEmail` (was inverted).

### CanvasManifest.json / control templates
- `AppDescription` "v0.8.14…" → "v0.9.17…"; `BindingErrorCount` 49 → 329. Added modern control templates `modernText_1.0.0.xml`, `modernTextInput_1.1.1.xml`. No platform-format upgrade; no screen additions/removals (22 screens).
