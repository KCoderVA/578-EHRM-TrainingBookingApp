feat(powerApps): v1.3.5 — MasterScheduleList scheduling migration, Success binding-error fix (24→3), richer user capture, Teams connector removed

## Context

This commit delivers the **578 EHRM Training App** repo with the **v1.3.5** feature/maintenance release — a Canvas-app data-source-modernization and reliability update that also completes the classic → modern control migration. The changes were made hands-on in the Power Apps canvas editor; the updated `.msapp` package (`v1.3.5_578EHRMTrainingApp.msapp`) was unpacked via `pac canvas unpack` and the resulting source files under `src/powerApps/.unpacked/` now reflect the v1.3.5 state. The analysis was produced by diffing the archived v1.1.20 unpacked source against the freshly unpacked v1.3.5 source.

The Canvas app component version advances from v1.1.20 → v1.3.5, now aligned with the project-wide SemVer release version (project `VERSION` advanced 1.2.8 → 1.3.5; the interim 1.2.8 bump was never released and is consolidated here).

## What changed — Canvas app (src/powerApps/)

### Screen additions / removals
- None — no screens were added or removed (all existing screens retained).

### Supervisor scheduling migration (POCSUPERVISOR.fx.yaml)
- Active role/scenario/date-time picker logic re-based from the national `Learning Lab Sessions` SharePoint list onto the app-owned `MasterScheduleList`, using `RoleName_text`, `ScenarioName_text`, `TrainingCombinedDateTime_text`, `LocationCombined_text` and an active-session filter `(IsBlank(sessionActive_text) || sessionActive_text <> "false")`.
- Added `btn_patchMasterScheduleList_scenarioDescription_multitext` — a bulk `Patch()` that back-fills the new `scenarioDescription_multitext` column on `MasterScheduleList`.
- People-picker rewritten to live `Office365Users.SearchUserV2` Graph search with an impersonation-aware `targetProfile`.
- Legacy `Learning Lab Sessions` queries commented out in place (with a dated developer note).

### Success screen status fix (Success.fx.yaml) — closes v1.1.20 KI-02
- Status-summary display reworked to the tier-flag model (`varDetailedListPatchOK`, `varFallbackOK`, `varSimpleListPatchOK`, `varEmailOK`), SuperUser line gated by `user_IsSuperUser`.
- `CanvasManifest.json` `BindingErrorCount` 24 → 3; App-Checker type-equality error class cleared.

### User administration (ManageUsers.fx.yaml)
- Expanded Entra/Graph capture via `Office365Users.UserProfileV2` / `ManagerV2` (department, job title, hire date, network account, full address, manager chain + photo); approver identity captured; Graph people-picker. Writes existing `DeskAccessControl` columns (no schema change).

### Data explorer (Screen1.fx.yaml)
- Power BI embed re-pointed (`WorkspaceId` f9a21156… → 4359a8a2…; `DashboardId` e948a0b5… → 5045c9a5…; `TileId` 550f8ee5… → 68eb7b98…) and re-enabled (`Visible: =false` removed).

### App / other
- `App.fx.yaml`: `varRepoVersion` "1.1.20" → "1.3.5"; impersonation gate hardened to `Lower(User().Email) = "kyle.coder@va.gov"`.
- `Dashboard.fx.yaml`: removed `Refresh('Learning Lab Sessions')` (deprecated list).
- `DebuggingScreen.fx.yaml`: two cards re-pointed `Description_multilineText` → `Description_multilinePlainText` (binding fix).
- `chkWeekDays.fx.yaml`: recurrence `maxOccurrence` cap logic refined.

### Connections / schema
- Removed the unused Microsoft Teams connection + `DataSources/MicrosoftTeams.json` + `pkgs/Wadl/MicrosoftTeams.xml` (closes v1.1.20 KI-03).
- New column `MasterScheduleList.scenarioDescription_multitext`; `Learning Lab Sessions` dataset path normalized (`/Sandbox/` → `/Sandbox`); duplicate SharePoint site key consolidated.

### Platform-wide modernization
- Classic glyph icons → modern `icon`; printable/phone screen layout templates flattened; legacy `group` control retired; modern-control default-property serialization; `ZIndex` renumbering. (Raised App-Checker accessibility findings — see known issues.)
