## Changes

### Power Automate — new `SendReminders` ("Send Email Reminder") flow

Previously the app had no automated way to notify a user once they were scheduled for an EHRM Learning Lab training session; the roadmap tracked building a reminder flow as a prerequisite to operationalizing the reminder fields.

**What it does:** when a user is scheduled, the flow reads their record from the `DeskAccessControl` SharePoint list and emails them an Adaptive Card titled **"You are scheduled for EHRM Learning Lab training!"** summarizing the key details:

| Field | Source |
|---|---|
| Name | `DeskAccessControl.DisplayName_Text` |
| Email | `DeskAccessControl.UserPrincipleName_Text` |
| Role | `DeskAccessControl.AccessLevel_Text` |
| Scheduled by | item `Author` (email) |
| Access window | `DeskAccessControl.AccessStop_dateTime` |

The standalone card design is kept at `src/powerAutomate/SendReminders/adaptiveCards/v0.12.4_flowSendReminders_adaptiveCard.json` for editing; the flow definition also embeds the card inline.
