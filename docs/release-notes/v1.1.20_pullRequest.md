## Canvas app changes — detailed breakdown

### 1. Resilient booking-commit orchestration (`Confirm`)
`btnSubmit` no longer does everything inline then jumps to Success. It now `Select()`-chains dedicated buttons (post calendar → patch reservation → sync SuperUser → send email), each setting a success flag, and a new **`timer_selectBtnsThenNavigate`** rolls those into `varAllOK` before `Navigate(Success)` — with a grace delay (2s success / 8s failure / 12s debug). Partial failures are now observable instead of silently landing on "Success."

### 2. Tiered both-lists fallback cascade (`Confirm`)
Reservation writes degrade gracefully through four tiers (`btnPatch_detailedPrimary` → `detailedSecondary` → `simplePrimary` → `debugSimplified`), and **every tier writes to both** `'Desk Reservations'` and `backupList_DeskReservations`. A per-submission `varSubmissionID` (GUID) tags the rows. Controls renamed to `btnOutlook_*` / `btnPatch_*`; legacy `btnOldSubmit` retained but disabled.

### 3. Rebuilt in-app Help screen (`ReleaseNotes`)
`htmlText_userGuide` (10-step end-user Quick-Start guide) + new `htmlText_releaseNotes` (admin full-changelog view), mutually exclusive on `user_isAdmin`.

### 4. Smarter class/scenario picker (`POCSUPERVISOR`)
Role/Scenario/Date-Time/Location dropdowns re-pointed to Hines-scoped collections; Date/Time picker adds a `sessionActive_text` active-session filter; cascade `Reset()` clears stale downstream picks. (Edit-form data-card churn is reordering only — no bound-column change.)

### 5. Naming/cleanup + misc
`Dashboard` `Timer3` → `timer_loadGlobalVariables`; `App` `varRepoVersion` stamp + `Text("Hines")` simplification; `DebuggingScreen` dev-cleanup lines disabled; `chkWeekDays` disarms the new Confirm timer var; confirmation-email `Cc` typo fixed. `Screen1` repurposed to an experimental (menu-unlinked) session-vs-schedule browse view with the Power BI tile hidden.
