chore(repo): v0.3.6 — .gitignore overhaul, data/archive file type rules, v0.3.5 artifact rotation, documentation catch-up

## Context

This commit delivers the **578 EHRM Training & Booking App** repo's **v0.3.6** patch release — a repository hygiene and security hardening update that comprehensively expands `.gitignore` coverage to block accidental commits of sensitive VA data files (CSV, XLSX, etc.), compressed binary exports (7z, gz, rar, etc.), and local-only configuration content (`config/`). Changes were made directly in VS Code via file edits; no Canvas app, Power Automate, or SharePoint components were modified. This release also performs the routine post-release artifact rotation from v0.3.5 and brings project-wide documentation (`README.md`, `docs/PROJECT_STATUS.md`) fully up to date through v0.3.6.

No component versions advance in this release. Canvas app baseline remains v0.3.4; `AppUserList` flow baseline remains v0.1.0.

---

## What changed — repository security (.gitignore)

### .gitignore — comprehensive overhaul
- Added `/config/` — now fully ignores the entire root-level `config/` directory; previously only `config/local/` and `config/logs/` were excluded; those redundant lines removed
- Added `/.git/` — explicit documentation-only entry (Git always protects this directory internally; redundant but intentional for developer clarity)
- Added full suite of compressed archive format rules — `**/*.7z`, `**/*.gz`, `**/*.bz2`, `**/*.tar`, `**/*.tgz`, `**/*.tar.gz`, `**/*.tar.bz2`, `**/*.rar`; previously only `*.zip` was covered
- Added spreadsheet and data list file type rules — `**/*.csv`, `**/*.tsv`, `**/*.xlsx`, `**/*.xls`, `**/*.xlsm`, `**/*.xlsb`, `**/*.ods`; blocks accidental commits of PII-containing or sensitive VA data files; the 10 sanitized CSVs currently tracked under `src/sharePoint/` are unaffected (tracked files are not auto-untracked by new `.gitignore` rules)
- Fixed `/docs/release-notes/releaseTemplates/` — added root-anchoring `/` prefix (was functionally working but not explicitly root-anchored)
- Removed redundant `config/local/` and `config/logs/` entries — now superseded by `/config/`
- Refreshed section numbering §1–§10; updated `Last updated` to 2026-07-14; added instructional inline comments to §9 and §10 guiding `!path/to/file` negation for per-file exceptions
