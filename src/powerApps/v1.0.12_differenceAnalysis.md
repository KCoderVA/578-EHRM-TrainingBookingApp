# Canvas App — Difference Analysis `v0.12.2 → v1.0.12`

> **Audience:** the app owner and future maintainers.
> **Method:** git `HEAD` (**v0.12.2**, "OLD") vs. the working tree (**v1.0.12** public release, "NEW")
> across `src/powerApps/.unpacked/`. Findings are read from the Power Fx
> `*.fx.yaml`, `DataSources/*.json`, `pkgs/TableDefinitions/*.json`, and `CanvasManifest.json`.
> `*.editorstate.json` files (editor UI state, not functional) were excluded.
> **Magnitude:** 41 source files changed, ≈71,700 insertions / ≈47,600 deletions (incl. editor state).

---

## 1. Executive summary

| # | Headline change | Impact |
|---|---|---|
| 1 | **Removed a hard-coded developer impersonation backdoor** in `App.OnStart` | Security — the app no longer silently spoofs one developer's identity to another user. |
| 2 | **RBAC rewritten to "default everyone to `User` first"** | Reliability — eliminates a SharePoint-write race that could leave brand-new users at `AccessDenied`. |
| 3 | **Single-student proxy registration** (POC/supervisor registers on behalf of a student) | New core workflow. |
| 4 | **Learning Labs Library class/scenario picker** (new read-only SharePoint doc library) | New feature; only genuinely new data source. |
| 5 | **Binding errors driven 120 → 0** | Quality — pervasive `IsBlankOrError()` guards + two real control bug fixes. |
| 6 | **Two dead template screens removed** (`CreateMeeting`, `Screen3`) | Cleanup; 21 → 20 screens. |
| 7 | **Partial classic → modern control migration** | Modernization; hybrid state (host control enabled). |
| 8 | **Learning Lab Sessions scoped to the Hines facility** | Correctness — no longer loads national data. |

**Version identifiers:** `Set(varRepoVersion, "0.12.2")` → `"1.0.12"`; `CanvasManifest.AppDescription`
`"v0.12.2 …"` → `"v1.0.12 …"` (both source strings standardized to the public release v1.0.12). A stray
internal `App.OnStart` comment references `v0.14.25` — treat inline comment version tokens as unreliable.

## 3. Global — `App.fx.yaml`

All change is inside `OnStart` (`StartScreen: =Dashboard`, `Theme`, `BackEnabled:=false` unchanged). The
old logic is preserved verbatim inside a trailing `/* … PREVIOUS CONTENT … */` comment block.

### 3.1 Removed impersonation backdoor (security)
```powerfx
// OLD (v0.12.2) — hard-coded spoof
If( Lower(User().Email) = "kyle.coder@va.gov",
    Set(varRealEmail, Lower("Matthew.Olson@va.gov")),
    Lower(User().Email) <> "kyle.coder@va.gov",
    Set(varRealEmail, Lower(User().Email)) );

// NEW (v1.0.12) — real signed-in identity
Set(varRealEmail, Lower(User().Email));
Set(varRealEntraID, First(Office365Users.SearchUserV2({searchTerm: varRealEmail, top: 1}).value).Id);
Set(varTargetEmail, varRealEmail);
Set(varTargetEntraID, varRealEntraID);
Set(varIsImpersonating, varTargetEmail = "kyle.coder@va.gov" && varRealEmail <> varTargetEmail);
```
The proxy model is retained via `varTargetEmail`/`varTargetEntraID` (the identity the app is "acting as"),
but it now defaults to the real user and is switched only intentionally (POC registering a student).

### 3.2 Learning Lab Sessions facility-scoped
```powerfx
// OLD
ClearCollect(col_nationalEHRMLearningLabSessions, 'Learning Lab Sessions');
// NEW
ClearCollect(col_nationalEHRMLearningLabSessions,
    Filter('Learning Lab Sessions', Facility.Value = Text("Hines")));
```

### 3.3 RBAC — "default to User first"
The old flow depended on a SharePoint write completing before the menu could resolve (fallback level
`"AccessDenied"`). The new flow sets a safe baseline first, then upgrades existing users in-memory or
fire-and-forget provisions a new one **without re-reading**:
```powerfx
Set(user_isAdmin, false); Set(user_IsSuperUser, false);
Set(userAccessLevel_text, "User");                       // baseline for anyone with network access
Set(varDeskAccessControl_record, LookUp(DeskAccessControl, Email_Text = Lower(varTargetEmail)));
Set(varUserExists, !IsBlankOrError(varDeskAccessControl_record));
If( varUserExists,
    Set(userAccessLevel_text, Coalesce(varDeskAccessControl_record.AccessLevel_Text,
        varDeskAccessControl_record.AccessLevel_Choice.Value, "User")),
    If( Lower(varTargetEmail) = Lower(varRealEmail),
        Patch(DeskAccessControl, Defaults(DeskAccessControl), {
            Email_Text: varRealEmail, AccessLevel_Text: "User", AccessLevel_Choice: {Value:"User"},
            Id_Text: varRealEntraID, AccessStart_dateTime: Now(),
            AccessStop_dateTime: DateAdd(Now(), 6, TimeUnit.Months),
            Approver_Email_Text: varRealEmail, Title: varRealEntraID,
            AboutMe_Text: "New 'User' access granted to 578 EHRM Training App at " & Now() }) ) );
Set(user_isAdmin, userAccessLevel_text = "AppAdmin");
Set(user_IsSuperUser, userAccessLevel_text = "SuperUser");
```
The self-provisioned record is now richer (6-month `AccessStart/Stop` window, `Approver_Email_Text`,
`Id_Text` Entra ID, `AboutMe_Text` audit stamp). Fallback level `"AccessDenied"` → `"User"`.

### 3.4 Other OnStart changes
- **Removed** the ~60-line block of `Set(var…, Blank())` initializers; equivalent cleanup relocated to the
  `Success` screen exit (preserving identity vars).
- **Added** `Host As hostControl.DefaultHostControlVariant` (enables modern controls app-wide — see §6).
- Refresh targets (7) and collections (`colDeskAccess`, `col_MasterSchedule`, `colUser_details` via
  `Office365Users.UserProfileV2(varTargetEntraID)`, `col_SuperUserList`, `col_backupDeskReservations`,
  `col_nationalEHRMLearningLabSessions`) are otherwise unchanged.

## 4. Screens — functional detail

### 4.1 `POCSUPERVISOR` — single-student proxy registration + class picker
- **Multi-attendee → single student.** `Set(var_Attendees, Concat(DataCardValue3.SelectedItems, Email, ";"))`
  → `Set(var_Attendees, DataCardValue3.Selected.Email)`.
- **Proxy identity switch** on student selection:
  ```powerfx
  Set(varTargetEmail, DataCardValue3.Selected.Email);
  Set(varTargetEntraID, First(Office365Users.SearchUserV2({searchTerm: DataCardValue3.Selected.Email}).value).Id);
  ClearCollect(colUser_details, Office365Users.UserProfileV2(varTargetEntraID));
  Set(varStudentMgrMail, Office365Users.ManagerV2(DataCardValue3.Selected.Email).userPrincipalName);
  ```
- **New structured pickers** `dropdown_RolePicker / ScenarioPicker / DateTimePicker / LocationPicker`
  (reset together), replacing the older `DropdownCanvas1` + manual `HourValue*/MinuteValue*` approach.
- **Class/scenario picker** backed by `Filter('Learning Labs Library', …)`; surfaces the scenario's
  materials link `https://dvagov.sharepoint.com/sites/vacoehrmioeue/Sandbox/LearningLabsDocs/Forms/AllItems.aspx`
  (`var_scenarioTrainingMaterialsURL`).
- **Navigation:** now `Navigate(chkWeekDays)` (the old direct `//Navigate(Confirm)` is commented out).

### 4.2 `chkWeekDays` — recurrence engine
Builds `CollectionRecurrence` (weekday expansion) and routes to `Confirm`. Diff is dominated by
confirmation-email HTML formatting (bold scenario name, dropped prefix).

### 4.3 `Confirm` — booking commit (Outlook + hardened Patch)
- **Calendar invite** upgraded `V2CalendarPostItem` → `Office365Outlook.V4CalendarPostItem(...)`; subject:
  ```powerfx
  Concatenate("578 EHRM Learning Lab - ", var_reservationScenario,
      If(IsBlank(varRecurrenceID), "", " (#" & varRecurrenceID & ")"))
  ```
- **Confirmation email** `Office365Outlook.SendEmailV2(...)`, subject
  `"[REGISTERED] EHRM Learning Lab Training - " & var_reservationScenario & " (" & var_reservationRole & ")"`.
  > This exact subject is the trigger contract for the new **`CreateBackups`** flow.
- **Virtual/physical location picker** (`dropdown_LocationPicker`) drives `var_reservationDivision`
  (always `"Edward Hines Jr. VA Hospital"`) with Room/Floor/Building set to `"Virtual"` / `"Virtual CBOC"`
  or physical numbers.
- **Defensive `Patch`** (the main driver of 120 → 0 binding errors): every field wrapped, e.g.
  ```powerfx
  reservationRoom_text: If(IsBlankOrError("Room " & var_reservationRoomNumber), "(not provided)", "Room " & var_reservationRoomNumber),
  reservationAgreementBody_multilinetext: If(!IsBlankOrError(var_reservationAgreementBody), var_reservationAgreementBody,
      !IsBlankOrError(HtmlText3.HtmlText), HtmlText3.HtmlText, "(not provided)"),
  ```
- **Self-vs-proxy description** in `reservationDescription_multilinetext`
  (*"Self-registered student…"* vs *"{varRealEmail} has registered student ({studentUPN})…"*).
- **Recurrence write loop** `ForAll(CollectionRecurrence As rec, ForAll(… Patch('Desk Reservations', …)))`
  — one row per occurrence, grouped by `varRecurrenceID`. Rebuilt in modern controls (`modernText`/`modernButton`).

### 4.4 `Success` — post-booking
Adds the reservation-variable cleanup relocated from `App.OnStart` (preserves identity vars),
`Refresh(SuperUserList)`, and its own `ForAll(CollectionRecurrence …)` write path. Exits to `Dashboard`.

### 4.5 `scrn_DailyCal` / calendar cluster
`scrn_DailyCal` adds **series-vs-single cancellation** (`Items: =["This Reservation","Series"]` +
`Remove('Desk Reservations', varSelectedReservation)`) and migrates galleries from `SortByColumns(...)`
to `Sort(Filter('Desk Reservations', …), …, SortOrder.Ascending)`. The three calendar views cross-navigate
and each can jump to `Reservation` and `PDFScreen`.

### 4.6 `ManageUsers` — bulk SuperUser autosync
Reconciles `SuperUserList` into `DeskAccessControl`, batched to 3 per run:
```powerfx
ClearCollect(colSuperUsers, SuperUserList);
ClearCollect(colMissingSuperUsers, Filter(colSuperUsers As SU, /* email not already in DeskAccessControl */));
Patch(DeskAccessControl, ForAll(FirstN(colMissingSuperUsers, 3) As SU, {
    AccessLevel_Choice: {Value:"SuperUser"}, AccessLevel_Text: "SuperUser",
    AboutMe_Text: "Bulk SuperUser autosync, triggered by " & varRealEmail & " on " & Text(Now()) }));
```

### 4.7 `NewDesk` / `Reservation` / `MyAppts`
- `NewDesk`: asset-type switch (`Desk`/`Room`/`Floor`/`Building`); title `"EHRM Training " & ddAsset.SelectedText.Value & " #…"`; `MapLink` text → `LocationMap_image.Full`.
- `Reservation`: `DisplayMode = If(userAccessLevel_text in {"View-Only","AccessDenied"} || blank, View, Edit)`; cancel comment `"Canceled by " & varRealEmail & " @ " & Now()`.
- `MyAppts`: match filter adds `'Created By'.Email`; requires `!IsBlankOrError(DeskText)`.

## 6. Data sources

### New (the only genuinely new source)
**`Learning Labs Library`** — a **read-only SharePoint document library**
(`IsWritable:false`, `x-ms-permission:read-only`) on site
`https://dvagov.sharepoint.com/sites/vacoehrmioeue/Sandbox` (`EntityName: "Learning Labs Library"`).
Custom columns include `EHRM_x0020_Track`, `Facility`, `Scenario`, `Service_x0020_Type`, `ServiceLine`,
`Status`, `Doc_x0020_Type`, `Ver`, `OData__ExtendedDescription`. Referenced ~13× in `POCSUPERVISOR` to
power the class/scenario picker.

### Stability
The underlying **data model is stable** between v0.12.2 and v1.0.12. `DataSources/*.json` and
`pkgs/TableDefinitions/*.json` diffs are empty or single-line metadata churn. The columns the new formulas
rely on (`Desks.ItemType_text/LocationMap_image/FloorNumber_number/BuldingNumber_number/RoomNumber_number`,
`Desk Reservations.reservationDescription_multilinetext/DeskText/reservationDivision_text/reservationAgreementBody_multilinetext`)
**already existed in v0.12.2** — the new version simply *starts using* them. No data sources removed.

## 8. Navigation / routing

**Automation model:** a workspace search for `*.Run(` returns **zero** — the canvas app invokes no Power
Automate flows directly; all automation is via `Office365Outlook`/`Office365Users`. Flows run
independently (see [`../powerAutomate/README.md`](../powerAutomate/README.md)).

Booking path: `POCSUPERVISOR → chkWeekDays → Confirm → Success → Dashboard`. Calendar cluster:
`scrn_MoCalendar ↔ scrn_WeeklyCal ↔ scrn_DailyCal`, each → `Reservation`/`PDFScreen`/`Dashboard`. Asset
management: `ManageDesks → NewDesk` (New) / `NewEditDesk` (Edit). Menu targets (Dashboard, MyAppts,
ManageDesks, ManageUsers, ReleaseNotes, POCSUPERVISOR) are unchanged. `CreateMeeting`/`Screen3` removal
left no dangling `Navigate()`. `Screen1` (new) has no inbound navigation.

## 9. Reliability (binding errors 120 → 0)
- `Tabs`/`Tabs_3` empty-collection `TemplateSize` guards; `Tabs_3` `&`→`*` width fix; `Calendar` hex fix.
- Pervasive `IsBlankOrError(...)` fallbacks across `Confirm`.
- Consistent `varRealEmail` (instead of `User().Email`) in audit trails so they remain correct under proxy.
- Manifest flags: `optimizestartscreenpublishedappload: true`, `generatedebugpublishedapp: true`.
